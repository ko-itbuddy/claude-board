## 직접 실행 시험 — 꼭 지킬 것

- **시험 빌드만**: `./build-board.sh --dev` → `open "dist/dev/Claude Board Dev.app"`(반드시 `open` — 직접 실행하면 이 세션 환경을 물려받음). 끄기 `pkill -f "Claude Board Dev.app/Contents/MacOS"`. 끝나면 `ps -o ppid= -A | grep -cw <보드 pid>` 가 0 인지.
- **설치된 보드 피하기**: 설치된 보드는 "위에 고정"으로 화면 오른쪽(x≈1226~1680)을 덮는다. 시험 빌드 보드 폭을 넓혀 목록 왼쪽이 보이게: `defaults write com.claude.board.dev boardPaneWidth -float 1000`. 접힌 시험 빌드를 누를 때는 `ui … move 100 33` 으로 옮긴다. 설치된 보드 가장자리 근처는 누르지 않는다(창 밖 몇 pt 가 크기 조절 영역 — 한 번 폭을 바꿔 버려 메뉴 "처음 크기로 오른쪽에 붙이기"로 되돌림).
- **도구**(`시험 도구/`, 스크래치에 `swiftc -O <파일> -o <스크래치>/이름` 로 빌드): `ui 조작 도구.swift` — `ui <pid> <창 제목 표지> front|frame|click x y|drag|type 글자|key 번호 [cmd,shift,ctrl,opt]|press 제목|presslike 글자|move x y|clickwin x y|globalkey 번호 수정키`. 표지는 "(시험 빌드)", 시트·메뉴는 "*". 매번 맨 앞 앱·창 제목·그 자리의 맨 위 창(다른 앱 창은 8pt 넓혀)을 확인한다. `창 찍기.swift`(winshot pid 출력 [all]), `이미지 자르기.swift`, `이미지 잇기.swift`, `좌표의 창.swift`, `stream.py`+`gaps.py`(숨김 출력 시험), `detach.py`(조상에 탭이 있는 tty 없는 claude -p), `rec.py`(바이트 기록), `한글 입력 드라이버.swift`.
- **좌표**: winshot 은 창 하나를 2배 픽셀로 찍는다 → 화면 pt = (창 x + px/2, 창 y(펼침 33) + py/2). 가능하면 `presslike`(손쉬운 사용)가 정확하다 — 새 세션 창 경로 줄 "workspace/claude-board", 카드 "+" 는 "추가"(카드마다 있어 첫째가 눌림 주의).
- **카드는 좌표로 누르지 않는다**: 그룹 순서·서브에이전트 줄이 1초마다 바뀌어 빗나간다(끝난 세션 줄을 잘못 누르면 사용자 세션을 이어 연다). `카드 메뉴 누르기.swift`(`axrow <pid> <카드 제목 글자>` — 제목이 든 카드가 하나일 때만 그 ⋯ 를 손쉬운 사용으로 누름, 메뉴는 열리지만 -25204 를 돌려주니 항목은 ↓/Return)로 누르고, 시험 빌드 설정 `pinnedGroups`(claude-board 그룹 고정)·`endedOpen`(종료된 세션 칸 접기)으로 배치를 고정한다(끝나면 되돌림). `AX 트리 찍기.swift` 로 창 구조를 본다. 프로세스가 끝나는 시각은 `종료 시각 재기.py`.
- **Ghostty 시험 창**: `zsh -l` 로 띄우면 `claude` 를 못 찾으니 `~/.local/bin/claude` 전체 경로. 입력은 그 터미널 id 에만. 시험 빌드에는 Ghostty 자동화 허용이 있다(2026-10-17 사용자 허락).
- **입력**: 입력기 ABC 에서 `type`(실제 키 번호). 한글은 드라이버(⌃⌥Space 전환, 끝나면 되돌림).
- **시험 claude 세션**: 작업 경로는 저장소(신뢰한 폴더). 띄운 뒤 프로세스 인자의 `--session-id` 로 `~/.claude/notifier/sessions/<id>.mute` — **세션 json 이 생긴 뒤에** 만든다(state.py 가 짝 없는 표지를 치운다). 사용자 hook 이 단독 `sleep` 을 막으니 오래 걸리는 요청은 `python3 -c "import time; time.sleep(45)"`. 이 세션의 Bash 에서 claude 를 띄울 때는 `env $(env | grep -o '^CLAUDE[A-Z_]*\|^AI_AGENT\|^CODEX_COMPANION_[A-Z_]*' | sed 's/^/-u /') …`. 시험 뒤에는 첫 요청이 시험 문구인지 확인한 것만 json·mute·paused·`~/.claude/projects/*/<id>.jsonl` 을 지운다.
- 보드 동작 시험은 `"dist/dev/Claude Board Dev.app/Contents/MacOS/ClaudeBoard" --action pause|resume|stop|reopen|focus <세션 id>` 로도 된다(메뉴와 같은 함수).
- 알림 패널 시험: `swiftc -O ClaudeNotifier.swift -o <스크래치>/notifier-dev` 후 `--activate com.claude.board.dev --session <id> --duration 20 --sound ""`, `ui <패널 pid> "*" clickwin x y`(층 25 — 컴파일하는 동안 표시 시간이 지나지 않게).
- 앱을 일부러 죽게 했으면 `~/Library/Application Support/CrashReporter/ClaudeBoard_*.plist` 를 지운다(실행 파일 이름으로 묶여 설치된 보드에도 "창 다시 열기" 창이 뜬다). 클립보드를 바꿨으면 되돌린다.
- 이 저장소의 Swift 파일을 고치면 이 세션의 sourcekit-lsp 가 패키지를 풀며 키체인(github.com) 암호 창을 띄울 수 있다 — SecurityAgent 가 맨 앞이면 `ui <SecurityAgent pid> "*" press "거부"`.

## 다음 세션 작업 방식 (컨텍스트 비용 줄이기 — 2026-10-17 사용자 요청)

- 메인은 계획·조율·검증 판단만 하고, 구현과 GUI 시험은 서브에이전트에 맡겨 **결론(표·커밋·스크린샷 경로)만** 받는다. 서브에이전트에게는 이 문서·설계.md 의 해당 장·"직접 실행 시험" 절을 경로로 넘긴다(본문을 붙여 넣지 않는다).

- 스크린샷은 서브에이전트가 직접 보고 판단한다. 메인은 꼭 필요할 때만 한 장 본다.
